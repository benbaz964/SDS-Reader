Process

How it works

Three steps, no setup.

  1. 1

    Add your SDSs

    Pick individual PDFs, or point it at a folder (and its subfolders) holding hundreds of them.

  2. 2

    Upload your template

    Use the built-in summary, or upload your own .docx, .txt or .md with {{placeholders}}. It's remembered next time.

  3. 3

    Process

    Get one filled document per SDS, plus an optional combined spreadsheet for the whole batch.

Built for real-world SDSs

Reads any vendor's format.

GHS 16-section aware

Finds sections by structure, not by one supplier's layout. It's been tested on Fisher, Fuchs, INEOS, SC Johnson, Bartoline and more.

Ingredient breakdown

Composition, CAS numbers, concentrations, WEL limits and flagged carcinogen, mutagen, reprotoxic and sensitiser mentions, one table row per ingredient.

Verbatim wording

First aid, fire-fighting, spillage and handling text is copied from the source SDS, not paraphrased.

Your layout, your brand

Formatting, logos, headers and tables in your Word template are kept. Only the placeholders are replaced.

Private by design

No internet connection, no accounts, no telemetry. Your documents are processed on your PC and stay there.

Works on locked-down PCs

One self-contained program. No Python, no installer, no administrator rights.

Templates

Make any document a template.

Type placeholders in double curly braces wherever a value should go. When you upload a template, the app tells you which placeholders it recognised and flags any typos before you run a batch.

  • Start from the starter template, or use Save built-in template to edit in the app.
  • The full placeholder list is searchable in the app. Double-click one to copy it.
  • To get one table row per ingredient, put the {{row:substance_breakdown.…}} placeholders in a single table row.

Security & trust

Safe to run, easy to verify.

Built in the open

Every download is built automatically from the public source code by GitHub Actions and self-tested before it's published. Nobody uploads it by hand.

Checksums for every release

Each release lists SHA-256 hashes. To check your download, run Get-FileHash SDS-Reader.exe in PowerShell and compare.

Never overwrites your files

It only reads your PDFs and template. Outputs get new names ((2), (3)…) rather than replacing anything already there.

Only touches what it needs

No network access, no macros (macro-enabled templates are refused), and invalid or oversized PDFs are rejected before they're opened.

FAQ

Questions.

Windows says "Windows protected your PC". Is that OK?

That's SmartScreen. It shows for any new app that isn't code-signed yet. Click More info → Run anyway. If you'd like to be sure the file is genuine first, compare its SHA-256 hash with the one on the release page.

My work PC blocks the .exe. What can I do?

Try the portable .zip. Extract it to a folder (for example in Documents) and run SDS-Reader.exe from there. Some IT policies block programs that unpack themselves into a temporary folder, and the portable version doesn't do that. If your PC only allows approved software, ask IT to allow it. They can check the release checksums and the source code.

Does it need the internet, or send my documents anywhere?

No. Everything runs on your PC. The app makes no network connections. The only exception is an optional, off-by-default "local Ollama AI check", which talks only to an AI model running on your own machine.

Can it read scanned SDSs?

Only if the PDF has a text layer. For image-only scans, run them through OCR first (for example with the free ocrmypdf).

How accurate is it?

It's very good on standard 16-section GHS sheets, but it uses rules rather than a trained model. Treat the output as a time-saver, not an authority. Always check safety-critical information against the original SDS.
